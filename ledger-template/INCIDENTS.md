# Incident Index

| ID | Severity | Detected | Resolved | Commander | Record location | PIR | Status |
|---|---|---|---|---|---|---|---|

ID format: `INC-###`. Severity uses Sev1–Sev4 from `core/03-classifications.md`.

Status values: DECLARED, CONTAINED, ERADICATED, RECOVERED, CLOSED.

Rules:

- Restricted incident details live in approved restricted storage; this index
  holds only the pointer and status.
- Preserve evidence before cleanup; do not "fix" before capture.
- Post-incident review (PIR) is required for Sev1/Sev2 and feeds Phase 11.
- Use the incident template in the engineering manual for the record itself.
