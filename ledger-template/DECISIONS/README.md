# Decisions (ADRs)

Store approved architecture and significant technical decisions here as
`ADR-###-short-title.md`. Use the ADR template in the engineering manual.

Rules:

- One decision per file; link superseded ADRs instead of editing history.
- Include context, options, decision, consequences, and evidence/approval.
- Security-relevant decisions require Security Authority or delegate review.
- Agent tooling decisions also update the Agent Tooling Register.
