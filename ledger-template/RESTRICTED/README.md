# Restricted Records

This directory holds restricted registers such as `VULNS.md`. A directory name
does not enforce access control. Store vulnerability details, exploit
information, sensitive architecture, and Restricted evidence in a system with
appropriate, verified access restrictions, or move this folder to that system
during X-KICKOFF-T03.

Rules:

- Access is need-to-know, logged, and time-boxed where possible.
- Do not copy Restricted content into open ledger files, logs, prompts, or
  evidence without approval.
- Reviews of Restricted records require the Security Authority or delegate.
