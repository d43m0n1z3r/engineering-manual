# Vulnerability Register (Restricted)

> Store this register in approved restricted storage. Do not commit secrets,
> exploit details, sensitive architecture, or real personal data here.

| ID | Title | Severity | CWE | CVE | CVSS | Exploitability | Status | Affected asset/version | Owner | Due | Evidence | Retest |
|---|---|---|---|---|---|---|---|---|---|---|---|---|

ID format: `VULN-###`. Severity uses Critical/High/Medium/Low-Info.

Status values: Suspected, Confirmed, In Progress, Fixed, Verified, Accepted
(time-boxed with authority), False Positive, Duplicate.

Rules:

- Confirmed requires reproducible evidence; Suspected requires a validation plan.
- Fix targets follow `core/03-classifications.md`; SLA breaches are reported.
- Retest evidence is required before Verified/Closed.
- Restricted details (exploit steps, sensitive data) stay in restricted storage.
