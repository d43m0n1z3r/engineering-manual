## 5.3 Role-to-skill minimums (summary)

Levels refer to the Part 5 proficiency scale. Entries name the skill category
(`Cat N`) and the skill row from that category's table.

| Role | Mandatory minimum profile |
|---|---|
| Project Analyst | Cat 4 Requirements engineering and traceability L4; Cat 23 Technical writing L4; Cat 9 risk analysis L3; Cat 14 security awareness L2 |
| Software Architect | Cat 9 System design and architecture L5; Cat 8 API design L4; Cat 7 database engineering L3; Cat 12 cloud and IaC L3; Cat 14 security architecture L3; Cat 14 threat modeling L4; Cat 23 decision records and design communication L5 |
| UI/UX Engineer | Cat 5 UX design and research L4; Cat 5 accessibility engineering L4; Cat 5 frontend engineering L3; Cat 14 security awareness L2 |
| Frontend Developer | Cat 5 frontend engineering L4; Cat 5 frontend security L4; Cat 21 test automation and end-to-end testing L3; Cat 14 secure coding L3 |
| Backend Developer | Cat 6 backend engineering L4; Cat 6 authentication, session, and authorization engineering L4; Cat 8 API design L4; Cat 7 database engineering L3; Cat 14 secure coding and application security L4; Cat 19 applied cryptography L3 |
| Database Engineer | Cat 7 database engineering L4 to L5; Cat 7 DB security, backup, and recovery L4; Cat 7 query performance tuning L4; Cat 22 reliability engineering L4 |
| Security Engineer | Cat 14 application security L4 to L5; Cat 17 defensive security L4; Cat 18 incident response L4; Cat 19 cryptography and identity management L4; Cat 20 security automation and DevSecOps L4; Cat 16 vulnerability triage L4 |
| Penetration Tester | Cat 15 web and API penetration testing L4; Cat 15 professional and ethical practice (RoE) L5; Cat 11 network security assessment L4; Cat 23 security reporting L4 |
| DevOps Engineer | Cat 13 DevOps and platform engineering L4; Cat 12 cloud and IaC L4; Cat 10 Linux and containers L4; Cat 11 networking L3; Cat 20 supply-chain security L4; Cat 13 observability engineering L4 |
| QA Engineer | Cat 21 test design and test automation L4; Cat 21 non-functional testing L4; Cat 14 security testing basics L3 |
| Technical Reviewer | Cat 4 software engineering principles L4; Cat 14 application security L3; Cat 23 technical writing L4; plus breadth L3 across the stack in use |

**Competency validation procedure for agents.** Before an agent is assigned a role, run the *LAB/SEED/TC* validations against a sandbox project with seeded defects and known-answer tests. Record the results in the Agent Capability Register. Any agent failing a validation operates in a supervised mode (outputs reviewed by a higher-level agent or a human).
