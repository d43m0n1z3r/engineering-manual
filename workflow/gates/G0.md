## G0 — Authorization and Kickoff Gate

| Aspect | Definition |
|---|---|
| Entry | Sponsor request exists. |
| Required evidence | Charter, the Authority Register, the Access Register, the Authorization Baseline, the Process Profile, and the ledger initialized. |
| Acceptance criteria | Named humans for each gate. Agent permission tiers assigned. The process profile is recorded in the charter. ★ No active offensive testing is authorized yet. |
| Rejection conditions | Unclear ownership. Shared credentials. |
| Remediation | Clarify the authority. Reissue the credentials. |
| Approval authority | Sponsor and Security Authority |
