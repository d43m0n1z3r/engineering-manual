## Source task and objective

**Input validation, serialization, error handling, logging.**

## Execution instructions

Validate on arrival: type, length, range, format, and allowlist (syntactic) plus business-rule (semantic) validation. Reject unknown fields where feasible. Use safe parsers (limit size and nesting depth, disable XXE and unsafe deserialization of untrusted data). Encode output per context. Central error handler returns the standard error format with a correlation ID and **no stack traces or internals**. Log structured events (JSON) with correlation IDs. Never log secrets, tokens, full PANs, or raw PII (mask or hash). Log security events (login, failure, privilege change, access denial, and validation anomalies). Neutralize log injection (CRLF).
