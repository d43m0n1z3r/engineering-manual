## Source task and objective

**Authentication and session management.**

## Execution instructions

Prefer a vetted identity provider or library. Do not build a custom crypto or auth protocol. Passwords: **Argon2id** (verify the current OWASP parameters), or scrypt/bcrypt/PBKDF2 where mandated (note bcrypt's 72-byte limit, PBKDF2 for FIPS). Per-user salt (library-managed), optional pepper in the KMS. MFA and passkeys where required. Lockout and throttling with anti-enumeration. Session IDs from a CSPRNG, rotated at login and privilege change, with idle and absolute timeouts. If using JWT: pin the algorithm, validate `iss`, `aud`, `exp`, and `nbf`, use short lifetimes, and use refresh rotation with revocation. Never accept `alg=none`.

## Expected outputs

AuthN module, tests

## Validation

Negative tests: brute force, fixation, expired and tampered tokens, and enumeration.
