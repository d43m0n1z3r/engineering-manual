## Execution instructions

Write stories ("As a ⟨persona⟩ I want ⟨capability⟩ so that ⟨benefit⟩"). Write use cases for complex flows (actors, preconditions, main and alternate flows, postconditions). Write acceptance criteria in Given/When/Then, including negative and abuse paths (unauthorized, invalid input, and rate-exceeded cases).

## Expected outputs

Story Backlog, Use Case Specs, Acceptance Criteria
