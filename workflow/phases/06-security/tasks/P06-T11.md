## Source task and objective

**Security monitoring, logging, detection engineering**

## Execution instructions

Define the log sources (app, auth, DB audit, proxy/WAF, OS, cloud audit, CI/CD). Normalize the schema. Write detections mapped to ATT&CK techniques and to threat-model scenarios (credential stuffing, impossible travel, privilege change, mass data access, anomalous API errors, and new admin creation). Each detection has a severity, a triage playbook, a false-positive note, and a test (simulate the event, confirm the alert).

## Expected outputs

Detection catalogue, playbooks

## Validation

Each detection is **tested** (alert fires). Alert routing verified.
