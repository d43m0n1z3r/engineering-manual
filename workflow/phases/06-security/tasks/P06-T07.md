## Execution instructions

Follow OWASP WSTG and the ASVS at the chosen level, and the API Security Top 10: **AuthN** (credential policy, brute-force controls, MFA bypass, session fixation, token flaws, password reset flows). **AuthZ** (BOLA/IDOR, function-level access, privilege escalation, multi-tenant isolation, mass assignment, forced browsing). **Input handling** (injection classes, XSS, XXE, deserialization, SSRF, file upload, path traversal, open redirect). **Logic** (workflow bypass, race conditions, replay, coupon and price manipulation). **Config** (headers, CORS, TLS, verbose errors, default credentials, exposed admin and debug interfaces). **API** (rate limits, versioning, excessive data exposure, GraphQL depth and batching abuse). Use two or more test identities per role to test horizontal access.
