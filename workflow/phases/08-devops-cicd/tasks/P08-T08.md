## Source task and objective

**DNS, TLS, reverse proxy, edge**

## Execution instructions

Managed certificates with automated renewal and expiry alerts. TLS 1.2+ (prefer 1.3), strong ciphers, HSTS (after verification), OCSP stapling where available. Reverse proxy or WAF terminates TLS, applies rate limits, request size limits, and header hygiene. DNS: DNSSEC where supported, CAA records, and no dangling records (subdomain takeover prevention).

## Expected outputs

Edge config

## Validation
