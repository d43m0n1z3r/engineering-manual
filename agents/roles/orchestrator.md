# Orchestrator

> Generated from the [role catalogue](README.md). The catalogue remains
> the authoritative source for this role card.

## Primary responsibilities

Maintains the workflow state, schedules tasks, resolves dependencies, enforces gates, routes escalations, and compiles progress reports

## Owned artifacts

`STATE.md`, task graph, the gate dossiers

## Phases

All

## Approval authority

Task assignment and sequencing. Cannot approve gates.

## Prohibited actions

Mark a task done without evidence. Waive gates.
