# Gate Dossier Checklist

Use when assembling evidence for any gate G0–G10. The gate approval authority
verifies this checklist before recording approval.

- [ ] Gate ID, entry criteria, and approval authority identified.
- [ ] All required evidence IDs listed and current (not stale).
- [ ] Each acceptance criterion marked pass/fail with evidence reference.
- [ ] Critical security criteria verified; no agent waiver attempted.
- [ ] Waivers documented with reason, compensating control, owner, and expiry.
- [ ] Open risks, defects, and vulnerabilities disclosed with severity and owner.
- [ ] Traceability orphans checked where required.
- [ ] Human approvals recorded with authority, scope, and timestamp.
- [ ] Restricted evidence referenced by location, not copied into open storage.
- [ ] Reviewer independence confirmed.
- [ ] Gate decision recorded: pass, conditional pass, reject, or escalate.
