# Ledger and Evidence Integrity Checklist

Use at task handoff, gate review, and periodic audit.

- [ ] `STATE.md` reflects current phase, tasks, gates, blockers, and next actions.
- [ ] Task statuses match evidence; no VERIFIED/DONE without evidence.
- [ ] Evidence records contain required fields and immutable locations.
- [ ] Evidence is not stale relative to the commit/artifact it references.
- [ ] RTM has no unexplained orphans for the reviewed scope.
- [ ] Assumptions, decisions, defects, incidents, and risks are current.
- [ ] Logs are append-only and free of secrets/Restricted data.
- [ ] Restricted records are in approved restricted storage with access logging.
- [ ] Handoffs include artifacts, evidence, limitations, and verification steps.
- [ ] Graphify/agent memory refreshed when configured.
- [ ] No evidence, logs, or findings were deleted to simplify a result.
