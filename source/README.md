# Source Manual

`manual.md` is the frozen original generation input for this repository. It is
retained for audit and recovery; it is not a live mirror of the generated manual.

- Version at freeze: see `../manifest.json` (`manual_version`,
  `source_manual_sha256`).
- Post-generation changes are tracked in `../CHANGELOG.md` and may make the
  living manual diverge from this file.
- Do not edit `manual.md` to change the manual; edit the generated/living files
  and record the change. Regeneration, if ever needed, must be a deliberate,
  reviewed operation.
